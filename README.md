# Practical Statistics for Data Scientists

Repositori ini dibuat untuk memenuhi tugas individu mata kuliah Machine Learning and Deep Learning. Berisi reproduksi kode pemrograman serta kajian teoretis dari setiap bab berdasarkan buku Practical Statistics for Data Scientists karya Peter Bruce, Andrew Bruce, dan Peter Gedeck.

---

## Daftar Isi dan Ringkasan Bab

### Chapter 1: Exploratory Data Analysis
Membahas cara meringkas data menggunakan estimasi lokasi (mean, median, trimmed mean, weighted mean), estimasi variabilitas (standar deviasi, varians, IQR, MAD), eksplorasi data kategorikal, serta visualisasi data dasar (box plot, histogram, density plot).


### Chapter 2: Data and Sampling Distributions
Mempelajari konsep sampling bias, bias seleksi, distribusi sampling dari suatu statistik, Central Limit Theorem (Teorema Limit Pusat), standard error, teknik bootstrap resampling, dan confidence intervals (interval kepercayaan).


### Chapter 3: Statistical Experiments and Significance Testing
Membahas pelaksanaan A/B testing, uji hipotesis, p-values, t-tests, derajat kebebasan, ANOVA (Analysis of Variance), uji Chi-Square, dan penanganan multiple testing.


### Chapter 4: Regression and Prediction
Mempelajari regresi linier sederhana dan berganda, cara interpretasi koefisien, asesmen performa model (R-squared, RMSE, analisis residual), regresi logistik untuk klasifikasi, serta teknik regularisasi (Ridge dan Lasso regression).


### Chapter 5: Classification
Membahas berbagai algoritma klasifikasi seperti Naive Bayes, Linear Discriminant Analysis (LDA), K-Nearest Neighbors (KNN), Decision Trees, serta metrik evaluasi model (Confusion Matrix, Precision, Recall, F1-Score, dan ROC-AUC Curve).


### Chapter 6: Statistical Machine Learning
Mempelajari metode ensemble learning untuk meningkatkan performa prediksi, yang meliputi Bagging (Random Forest) dan Boosting (Gradient Boosting, XGBoost, LightGBM).


### Chapter 7: Unsupervised Learning
Membahas teknik pembelajaran tanpa pengawasan untuk reduksi dimensi dan pengelompokan data, yang mencakup Principal Component Analysis (PCA), K-Means Clustering, dan Hierarchical Clustering.
