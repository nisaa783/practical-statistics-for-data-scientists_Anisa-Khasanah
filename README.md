# Practical Statistics for Data Scientists

Repositori ini dibuat untuk memenuhi tugas individu mata kuliah Machine Learning and Deep Learning. Berisi reproduksi kode pemrograman serta kajian teoretis dari setiap bab berdasarkan buku Practical Statistics for Data Scientists karya Peter Bruce, Andrew Bruce, dan Peter Gedeck.

---

## Daftar Isi dan Ringkasan Bab

### Chapter 1: Exploratory Data Analysis
* **Ringkasan Teori:** Membahas cara meringkas data menggunakan estimasi lokasi (mean, median, trimmed mean, weighted mean), estimasi variabilitas (standar deviasi, varians, IQR, MAD), eksplorasi data kategorikal, serta visualisasi data dasar (box plot, histogram, density plot).
* **Implementasi Kode:** Menghitung statistik deskriptif dan membuat visualisasi menggunakan pustaka Python seperti pandas, numpy, matplotlib, dan seaborn.

### Chapter 2: Data and Sampling Distributions
* **Ringkasan Teori:** Mempelajari konsep sampling bias, bias seleksi, distribusi sampling dari suatu statistik, Central Limit Theorem (Teorema Limit Pusat), standard error, teknik bootstrap resampling, dan confidence intervals (interval kepercayaan).
* **Implementasi Kode:** Melakukan simulasi resampling bootstrap untuk mengestimasi ketidakpastian suatu estimator.

### Chapter 3: Statistical Experiments and Significance Testing
* **Ringkasan Teori:** Membahas pelaksanaan A/B testing, uji hipotesis, p-values, t-tests, derajat kebebasan, ANOVA (Analysis of Variance), uji Chi-Square, dan penanganan multiple testing.
* **Implementasi Kode:** Menjalankan uji statistik dan uji signifikansi menggunakan modul scipy.stats.

### Chapter 4: Regression and Prediction
* **Ringkasan Teori:** Mempelajari regresi linier sederhana dan berganda, cara interpretasi koefisien, asesmen performa model (R-squared, RMSE, analisis residual), regresi logistik untuk klasifikasi, serta teknik regularisasi (Ridge dan Lasso regression).
* **Implementasi Kode:** Membangun model regresi menggunakan pustaka scikit-learn dan statsmodels.

### Chapter 5: Classification
* **Ringkasan Teori:** Membahas berbagai algoritma klasifikasi seperti Naive Bayes, Linear Discriminant Analysis (LDA), K-Nearest Neighbors (KNN), Decision Trees, serta metrik evaluasi model (Confusion Matrix, Precision, Recall, F1-Score, dan ROC-AUC Curve).
* **Implementasi Kode:** Melatih model klasifikasi pada dataset terstruktur dan mengevaluasi performa prediksinya.

### Chapter 6: Statistical Machine Learning
* **Ringkasan Teori:** Mempelajari metode ensemble learning untuk meningkatkan performa prediksi, yang meliputi Bagging (Random Forest) dan Boosting (Gradient Boosting, XGBoost, LightGBM).
* **Implementasi Kode:** Mengimplementasikan algoritma ensemble untuk menangani data kompleks dan mencegah overfitting.

### Chapter 7: Unsupervised Learning
* **Ringkasan Teori:** Membahas teknik pembelajaran tanpa pengawasan untuk reduksi dimensi dan pengelompokan data, yang mencakup Principal Component Analysis (PCA), K-Means Clustering, dan Hierarchical Clustering.
* **Implementasi Kode:** Menerapkan algoritma clustering dan visualisasi hasil reduksi dimensi.
